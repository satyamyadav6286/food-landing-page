# 🍔 Food Landing Page

A modern, responsive, and visually appealing **Food Landing Page** built with **React** and **Vite**. This project showcases a clean user interface with smooth navigation, engaging sections, and a mobile-friendly design, making it ideal for restaurants, cafés, or food-related businesses.

---

## 🌐 Live Demo

🔗 **https://food-landing-page-ivory.vercel.app/**

## ✨ Features

- 🎨 Modern and attractive UI
- 📱 Fully Responsive Design
- ⚡ Fast Performance with Vite
- 🧭 Smooth Navigation

- 👨‍🍳 About Section

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/satyamyadav6286/food-landing-page.git
```

### 2️⃣ Navigate to the Project

```bash
cd food-landing-page
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
